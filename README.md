# Raveneer

Raveneer (Raven + Pioneer) es un videojuego móvil de supervivencia y exploración 2D con vista cenital, desarrollado en Unity para Android.

El jugador es un cuervo que debe mantenerse con vida: se alimenta, evita depredadores y explora el entorno para recolectar tesoros y llevarlos a su nido.

Su rasgo distintivo es el modo inmersivo con Realidad Aumentada. Al activarlo, el escenario virtual desaparece y la cámara del teléfono se convierte en una galería: el jugador fotografía tesoros flotantes en su espacio real, les pone nombre y los reúne en un álbum. Un sistema de logros premia las noches sobrevividas, los objetos recolectados y los tesoros coleccionados.
